# AniEdge for AMD 진행 상황

## 출발 목표

RX 9070 XT에서 PC에 저장된 애니메이션 MP4/MKV를 재생하면서 복원하는 플레이어를 만들었습니다. 오래된 480p 이하 영상의 화질을 개선하되 실시간 재생을 유지하는 것이 목표입니다.

## 현재 실행 프로그램 — HQ 전용

사용자 요청으로 HQ — Real-CUGAN Pro FP16만 남겼습니다. 자동 선택·원본·가벼운/강한 복원·HD 모드와 관련 옵션, ArtCNN/Anime4K 셰이더 및 실행 경로를 제거했습니다. FP32 모델은 개발 검증 자료로만 유지합니다. 가중치 재학습은 아직 시작하지 않았습니다.

## 이전 구현 기록

첫 재생 경로는 mpv와 Anime4K 셰이더를 연결했습니다. 원본·가벼운 복원·강한 복원 비교, 외부 자막, 일시정지·탐색, 별도 재생 창을 구현했습니다. 사용자 요청에 따라 복원 강도 자동 하향은 기본값에서 껐습니다.

고품질 복원 경로로 Real-CUGAN Pro conservative x2 ONNX를 DirectML에 연결했습니다. 전처리·추론·후처리를 포함한 첫 480p 처리량은 약 29fps였습니다. RGB 파이프를 이용해 전체 영상을 먼저 변환하지 않고 순차 재생하도록 만들었습니다.

다른 영상의 드롭을 확인하면서 실제 메타데이터를 조사했습니다. 15개 파일 중 13개는 이름의 360/480/720 표기와 달리 실제 2560×1440 약 60fps였습니다. 저해상도와 고해상도에 같은 무거운 모델을 적용하는 방식의 처리 부담을 줄이기 위해 경로를 분리했습니다.

480p급은 기존 Real-CUGAN 가중치를 유지하면서 FP16·GPU 전후처리·고정 입력 크기로 최적화했습니다. 같은 실제 프레임 60개에서 28.4 → 89.1fps를 측정했습니다. 15개 파일의 45개 장면에서 기존 FP32와 비교한 변환 오차 기준도 모두 통과했습니다.

HD·고FPS는 ArtCNN C4F32를 Vulkan 셰이더로 실행합니다. 원본을 작은 입력으로 줄이지 않고 CNN을 적용하며 mpv의 원본 시간축을 사용합니다. 1440p·60fps에서 GPU 렌더 패스 평균 합계는 약 10.9ms였습니다.

## 검증 상태

이전 v0.1.0-preview.1 릴리스는 자동 선택 경계 조건, 런처 초기화, 모델 로딩·추론, 실제 파일의 짧은 재생, 음성 동기화 수치, 종료 시 자식 프로세스 정리를 확인한 프로토타입입니다. 15개 파일을 약 10초씩 검사한 결과 13개는 드롭 0, 나머지는 시작 구간 4개·1개가 남았습니다. 모바일 1080p 샘플은 AI 없이 재생해도 시작 구간 드롭이 발생했습니다.

원본 영상·추출 프레임·개인 로컬 경로·실행 로그는 공개 저장소와 릴리스에 포함하지 않았습니다. 측정 JSON에는 익명 샘플 식별자를 사용했습니다.

## 다음 개선 항목

HQ의 원본 타임스탬프와 시간 탐색, 초기 드롭, 실제 4K 표시와 전체 에피소드 안정성, 장면별 선 깜빡임·글자·배경 복원 품질을 추가 검증해야 합니다. 모델 재학습에는 정렬된 HR/LR 대응 프레임과 별도 검증 영상이 필요합니다. 지금의 파일을 학습 쌍으로 가정하지 않았습니다.
